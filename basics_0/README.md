# Networking basics #0

Solutions for the first networking basics exercises.

- `0-OSI_model`: OSI model questions
- `1-types_of_network`: LAN, WAN, and Internet
- `2-MAC_and_IP_address`: MAC and IP address definitions
- `3-UDP_and_TCP`: transport protocol behavior
- `4-TCP_and_UDP_ports`: executable Bash script listing all listening sockets and their owning processes
- `5-is_the_host_on_the_network`: executable Bash script pinging an IP address five times

Run scripts with Bash on Ubuntu. The socket listing requires `netstat` from `net-tools` and permission to display process information.
